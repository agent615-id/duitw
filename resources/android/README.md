# Ikon Android duitw

Ikon launcher PNG per density dan foreground adaptive icon disertakan di folder ini.
Workflow GitHub Actions menyalinnya ke resource Android setelah Capacitor membuat project Android.
Jika membangun Android secara lokal, jalankan langkah salin ikon yang sama seperti pada
`.github/workflows/build.yml` sebelum menjalankan Gradle.
